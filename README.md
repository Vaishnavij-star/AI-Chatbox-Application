\# AI-Chatbox-Application 🤖



\*\*Intelligent AI Chatbot\*\* built with Python, Google Generative AI API, and MongoDB for conversational AI with sentiment analysis.



---



\## Features



\- Conversational AI with natural language understanding  

\- Sentiment analysis for each user message  

\- Memory storage using MongoDB  

\- Easy to run locally using Flask or CLI
