## ✨ About the Project

Vaishnavi's Ultimate Offline Chatbot is a smart, interactive chatbot designed to work **completely offline**. It can chat naturally, remember the user's name, tell jokes, answer general questions, play games, perform calculations, and much more.

This project is ideal for:

* Python beginners
* Resume & portfolio projects
* Offline demo applications
* Learning Streamlit deployment

---

## 🚀 Features

* 🗣️ Natural conversation & greetings
* 🧠 Remembers user's name
* 😂 Dad jokes, random jokes & one-liners
* 🎶 Song suggestions (romantic, chill, happy, sad)
* 🇮🇳 National Anthem of India
* 🤓 Fun facts & inspirational quotes
* 🧮 Math calculations (+, −, ×, ÷)
* 🎮 Mini games:

  * Rock–Paper–Scissors
  * Number Guessing Game
* ⏰ Current date & time
* 🌦️ Weather responses (offline preset)
* 💬 Chat history with colored chat bubbles

---

## 🛠️ Tech Stack

* **Python 3.9+**
* **Streamlit** (UI & deployment)
* **pytz** (timezone handling)

## 📦 Installation (Run Locally)

1️⃣ Clone the repository:

```bash
git clone https://github.com/Vaishnavij-star/AI-Chatbox-Application.git
cd AI-Chatbox-Application
```

2️⃣ (Optional) Create virtual environment:

```bash
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
```

3️⃣ Install dependencies:

```bash
pip install -r requirements.txt
```

4️⃣ Run the app:

```bash
streamlit run app.py
```
