# Vaishnavi's AI Chatbot 🤖

An AI chatbot built with Streamlit that remembers your name, tells jokes, and responds to small talk.

## Features
- Remembers user name
- Responds to greetings and questions
- Tells programming and fun jokes
- Chat history with colored bubbles
