# AI-Chatbox-Application 🤖

**Intelligent AI Chatbot** built with Python. Fully offline version available (no API needed) with jokes, songs, games, quotes, weather, time, and more!  

Vaishnavi's AI Chatbot remembers your name, tells jokes, responds to small talk, and more.

---

## Features

- Conversational AI with natural language understanding  
- Remembers user name  
- Responds to greetings and questions  
- Tells programming, dad, tech, and one-liner jokes  
- Suggests songs based on mood (happy, sad, love, chill, energetic)  
- National anthem of India  
- Fun facts and inspirational quotes  
- Simple math calculations  
- Plays small games (number guessing, Rock-Paper-Scissors)  
- Displays time and date  
- Chat history with colored bubbles
